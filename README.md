# TrustHub 🏡
TrustHub is an OLX-like classified web application where users can post listings and communicate with sellers in real-time using chat.

---

## 🚀 Features

- User Authentication (Login / Register)
- Post Listings with Image Upload
- Search & Filter Listings
- Real-time Buyer–Seller Chat (Socket.IO)
- MongoDB Database Integration
- Responsive UI
- Property Listings Dashboard
- Buyer Contact Seller Option

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- CSS
- Socket.IO Client

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- Multer (Image Upload)

## ⚙️ Installation

### 1. Clone Repository


git clone https://github.com/muskan23jics095-ai/Trusthub.git

cd Trusthub


---

### 2. Backend Setup


cd backend
npm install
npm start


Server runs on:

http://localhost:5000


---

### 3. Frontend Setup


cd frontend
npm install
npm start


Frontend runs on:

http://localhost:3000


---

## 💬 Real-time Chat

- Buyer clicks **Contact Seller**
- Chat window opens
- Messages sent using Socket.IO
- Messages stored in MongoDB
- Previous chat history loads automatically
